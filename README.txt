IMPORTANT: ORIGINAL MEDIA FILES
The ZIP supplied for this code update contained the six code files listed above, but did not contain the images/ or videos/ folders.

BOOKING BEHAVIOUR
- WhatsApp opens a prepared message to the business WhatsApp number.
- Email opens the visitor's default email application with a prepared message addressed to the business email.
- Email submission depends on the visitor having an email application or mail handler configured in their device/browser. A static HTML website cannot send email silently by itself; that would require a server-side email service.
